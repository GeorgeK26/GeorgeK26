## 🔬 Featured Projects

### 🏭 Industrial IoT Monitoring Controller

An **ESP32-based Industrial IoT monitoring and control system** designed to demonstrate practical industrial monitoring, fault handling, local HMI, and wireless telemetry.

The system monitors environmental and machine-related parameters and provides real-time operator feedback through an OLED display and alarm system.

#### ⚙️ Key Features

* 🌡️ DHT22 temperature monitoring
* 💧 Humidity monitoring
* ⚙️ Analog machine-load monitoring
* 📊 4-sample moving-average filtering
* 🔍 Sensor fault detection
* 🚨 Warning & critical alarm states
* 🔁 Alarm hysteresis
* 💡 LED & buzzer alarm outputs
* 🖥️ SSD1306 OLED local HMI
* 🎛️ Three-button navigation
* 📡 Wi-Fi monitoring
* 🔄 Automatic Wi-Fi reconnection
* 📦 JSON telemetry
* 📝 Event logging
* 🔔 Alarm transition detection
* 🖥️ Serial diagnostics

The firmware uses a **state-machine-based alarm architecture**, with dedicated `NORMAL`, `WARNING`, `CRITICAL`, and `SENSOR_FAULT` states.

#### 🧠 Technologies

`ESP32` • `C/C++` • `Arduino Framework` • `DHT22` • `SSD1306 OLED` • `Wi-Fi` • `ADC` • `Wokwi`
